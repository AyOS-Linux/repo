# Ayder — Custom Calamares for AyOS / Кастомный Calamares для AyOS

**Work In Progress / В разработке**

Ayder is a custom build of Calamares with its own theme, animations
and color palette, designed for AyOS Linux.
No installer functionality is available in this package yet.

Ayder — это кастомная сборка Calamares с собственной темой,
анимациями и цветовой палитрой, созданная для AyOS Linux.
Функциональность установщика в этом пакете пока недоступна.
